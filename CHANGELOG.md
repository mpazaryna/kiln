# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

This file records changes to **Kiln**. Behaviour that changes underneath us — a new OS
altering what the on-device model returns — is not a change to this project and belongs
in `.orchestra/devlog/` instead.

## [Unreleased]

`MARKETING_VERSION` is `0.1.0` and nothing is tagged yet. Everything below moves under a
`[0.1.0]` heading the day that tag exists.

### Added

- `Hello, Kiln` — a prompt, a Fire button, and a response, on iOS and macOS. The whole
  app so far, and deliberately so: it establishes config-driven layout, enum view state,
  and a provider reached through a protocol rather than named directly.
- `KilnModel` seam with `AppleIntelligenceModel` as its first conformance, resolved
  through `ModelRegistry`. Present from the first commit because comparing providers is
  the point of the lab (ADR-002).
- Generation failures mapped to `KilnGenerationIssue` rather than flattened to
  `localizedDescription`, carrying summary, recovery, and raw framework detail
  separately. The Simulator's missing guardrail assets are named explicitly instead of
  reported as a generic error (ADR-003).
- Xcode Cloud CI — post-clone and post-xcodebuild hooks, plus `scripts/run-tests.sh`
  with a zero-test guard shared with CI through `scripts/lib/xcresult.sh`. A green run
  that tested nothing fails.
- App Store Connect workflow script for creating the CI workflows via API.
- App icon, generated by a Pillow script rather than drawn, so it is reproducible and
  reviewable as a diff.
- `.orchestra/` knowledge base — ADR-000 through ADR-005, a five-milestone roadmap, stub
  PRDs, and a devlog.

### Changed

- The public-repository rule now distinguishes what it protects (client data,
  proprietary models, credentials) from what it had swept up by accident (Linear ticket
  references). A hard rule that is routinely stepped over costs the rules beside it
  their weight.

### Security

- `.mcp.json` is gitignored. It holds an API key in plaintext and nothing covered it, so
  a `git add -A` would have published it. Verified never committed — no history rewrite
  was needed and no key was exposed.
